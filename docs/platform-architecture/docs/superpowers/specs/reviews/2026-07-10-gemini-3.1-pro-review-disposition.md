Adversarial design review of `2026-07-10-autonomy-tevv-architecture-design.md` requested by zhihan, run via Antigravity CLI. Instruction: do not blindly accept. Each finding was verified against Argo/K8s/ROS 2 semantics, the existing sim stack's documented behavior, and the spec's actual text before acting. Raw review output is appended.

| 2 | BLOCKER | Uncompressed MCAP on ephemeral storage → DiskPressure eviction | **Accepted, fix improved** (spec never said emptyDir, but storage was unspecified — real gap) | Dedicated volume + rosbag2 split-by-size + rolling segment upload w/ local delete. But the discipline is right and cheap: Loki now carries run_id as structured metadata (better than both the original label design and the reviewer's scan-JSON-at-query-time), Prometheus keeps run_id only on run-scoped exporter series with node/dcgm/cadvisor cluster-scoped. | 4 | MAJOR | Argo priority doesn't preempt; nightly L3 starves PR smoke | **Accepted** | Correct — priority orders queues only. Semaphore partitioned: `gpu-sim-interactive: 1` (PR/merge) + `gpu-sim-batch: 1` (nightly/sweeps). Kueue deferred to growth. §7 |

| 9 | MAJOR | Over-engineered: drop QoS validation, replace compiler with Helm/Kustomize | **Mostly rejected** | Helm/Kustomize render K8s manifests only — the compiler's job is multi-artifact (AirSim settings.json, mavlink-router conf, FastDDS XML, evaluation.yaml, compose files) and it already exists as the Jinja generator; replacing working code with a less capable tool is a rewrite, not a simplification. Dropping QoS checks converts a 5-second compile error into a burned GPU slot + undiagnosed dead run — QoS mismatch is the documented silent-failure mode of this very stack. Accepted the underlying phasing caution: P1 ships type/wiring check only; QoS compatibility lands P2. §13 |

| 12 | MINOR | Auto-cancel isn't declarative in Argo | **Accepted** | Mechanism named: pre-submit step stops workflows matching `{pr, suite}` labels via Argo API. §7 |
| 13 | MINOR | Retry identity collision: reused run_id = PK collision; new run_id = skewed SLO | **Accepted — best catch in the review** | `attempt` column; pk (run_id, attempt); SLO counts attempts; verdicts attach to final attempt. §8, §9.1 |

| 15 | NIT | Air-gap strategy misses build-time deps (apt/pip) | **Accepted** | Harbor pull-through proxy + internal apt/PyPI mirrors added to the posture. §11 |

## Verdict on the review's verdict

"Immediate architectural collapse in Phase 1" is not supported by its own findings once the arithmetic and strawmen (emptyDir, liveness probes, compiler-from-scratch — none in the spec) are removed. What survives is valuable: the conductor-as-step responsibility fix, recorder disk-pressure handling, the attempt-identity model, lockstep as an explicit contract term, and four concrete P0/P1 potholes (CORS, DS addressing, auto-cancel mechanics, semaphore partitioning). Net effect: the architecture shape is unchanged; its failure-prone edges got named and specified.

## Appendix — raw review output (verbatim)

1. **BLOCKER** | **Section 7 & 8** — Conflation of Argo Workflow steps with K8s Deployments. Argo `withParam` spawns individual step pods; Argo cannot natively sequence a 10-pod topology, manage a readiness barrier, or cleanly tear it down mid-mission. Fix: the Argo step must be a single `run-conductor` pod holding a K8s API client.
2. **BLOCKER** | **Section 7 & 9.2** — Recording uncompressed MCAP bags to local pod storage triggers DiskPressure eviction. Fix: mount a PVC; exit handler uploads it.
3. **BLOCKER** | **Section 9.3 & 9.4** — High-cardinality run_id labels violate Prometheus/Loki TSDB design; Prometheus will bloat and OOM. Fix: drop run_id label; Pushgateway or Postgres for run telemetry; LogQL JSON filtering for Loki.
4. **MAJOR** | **Section 7** — Argo priorities don't preempt; L3 nightly hogs GPUs. Fix: partition semaphores or build a preemption controller.
5. **MAJOR** | **Section 8** — Wall-clock K8s probes vs sim-time: K8s will evict healthy stacks at low RTF. Fix: remove liveness probes from sim-dependent pods; conductor assesses topic Hz vs /clock.
6. **MAJOR** | **Section 6** — tc netem requires NET_ADMIN, violating default-deny. Fix: userspace proxy sidecar (e.g., Envoy or custom UDP forwarder).
7. **MAJOR** | **Section 10** — Pixel Streaming WebRTC can't route through standard ingress. Fix: static TURN/STUN (coturn) via NodePort/HostNetwork.
8. **MAJOR** | **Section 5.4** — FastDDS Discovery Server IP unknown at concurrent boot; DNS caching flaky. Fix: headless service + init-container nslookup wait.
9. **MAJOR** | **Section 5.2, 7, 9.1** — Over-engineering at pilot scale: bespoke compiler w/ QoS validation, custom telemetry-writer. Fix: drop QoS validation; use Kustomize/Helm.
10. **MAJOR** | **Section 9.2 & 10** — Foxglove browser clients can't stream from MinIO without presigned URLs + CORS (Access-Control-Allow-Origin, Range).
11. **MINOR** | **Section 9.4** — ServiceMonitor discovery latency (15–30 s) loses telemetry for short runs. Fix: Pushgateway or post-process only.
12. **MINOR** | **Section 7** — No native "cancel older workflow by PR" in Argo. Fix: pre-flight script against Argo API.
13. **MINOR** | **Section 8 & 9.1** — Retry identity collision: reused run_id = PK collision; new run_id = skewed SLO. Fix: distinguish trigger_id from attempt.
14. **MINOR** | **Section 6 & 8** — Missing lockstep enforcement: /clock-anchored faults vs wall-clock autopilot → EKF divergence on stutter. Fix: enforce lockstep (PX4_SIM_SPEED_FACTOR / SIM_SPEEDUP).
15. **NIT** | **Section 11** — Air-gap misses apt/pip at build time. Fix: Harbor pull-through proxy + internal Apt/PyPI mirrors.

Overall verdict (reviewer): spec is "theoretically clean" but underestimates K8s/robotics friction; predicted "immediate architectural collapse in Phase 1"; simultaneously over-engineered (compiler, DB API) and under-engineered (disk, WebRTC, DDS discovery); recommended centering orchestration in a conductor pod and standard data-plane retention.
